\section{Human Resources Planning}
The project has been entirely developed by the student, who has acted as the only project developer, assuming full responsibility for both the technical and organizational aspects required for its completion. The project developer has carried out all phases of the project, including the initial theoretical research, multi-agent environment design within simulation platforms, model integration, implementation of unprojection logic, and writing the final documentation. 

Complementing the development process, the project director maintained academic supervision from start to end. Acting as a mentor, the director offered essential methodological support while monitoring the technical integrity and logical flow of the study.
